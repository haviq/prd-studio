Use PRD Studio from your own tools.

A small OpenAI-compatible HTTP API. Point any client at the base URL below. All responses are plain JSON.

Base URL

https://prd.haaviq.dev

Endpoints

POST /api/suggest

Propose fields from an app name. Body: { "title": "...", "template": "..." }

POST /api/generate

Return a full PRD. Body: { "name", "description", "features", "users", "tech", "template" }

POST /api/diagram

Return diagram code and image URL. Body: { "kind": "arch" | "erd", "name", "description", "features" }

GET /api/health

Service status and configured models.

Generate a PRD

# generate a PRD
curl -X POST https://prd.haaviq.dev/api/generate \n  -H "Content-Type: application/json" \n  -d '{
    "name": "Scrapling",
    "description": "AI web scraping platform",
    "template": "Web App"
  }'

# response
{ "markdown": "## 1. Overview & Goals ..." }

Suggest fields

curl -X POST https://prd.haaviq.dev/api/suggest \n  -H "Content-Type: application/json" \n  -d '{ "title": "Scrapling", "template": "Web App" }'

# response
{
  "description": ["..."],
  "features": ["..."],
  "users": ["..."],
  "tech_stack": ["..."]
}

Diagrams

curl -X POST https://prd.haaviq.dev/api/diagram \n  -H "Content-Type: application/json" \n  -d '{ "kind": "arch", "name": "Scrapling", "description": "..." }'

# response
{ "kind": "arch", "code": "flowchart TD ...", "svg_url": "https://kroki.io/..." }

Rate limit: 20 requests per hour per IP. Responses are AI-generated; verify before relying on them. See the terms.
