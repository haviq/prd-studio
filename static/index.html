Documentation

Use PRD Studio from your own tools.

A small OpenAI-compatible HTTP API. Point any client at the base URL below.

Endpoints

POST /api/suggest

Propose fields from an app name. Body: { "title", "template" }.

POST /api/generate

Return a full PRD. Body: { "name", "description", "features", "users", "tech", "template" }.

POST /api/diagram

Return diagram code + image URL. Body: { "kind": "arch" | "erd", "name", "description", "features" }.

GET /api/health

Service status and configured models.

Quick start

Generate a PRD with a single request.

# generate a PRD
curl -X POST https://prd.haaviq.dev/api/generate \\
  -H "Content-Type: application/json" \\
  -d '{
    "name": "Scrapling",
    "description": "AI web scraping platform",
    "template": "Web App"
  }'

# response
{ "markdown": "## 1. Overview & Goals ..." }

Responses are plain JSON. Rate limit: 20 requests / hour per IP.

FAQ

Questions, answered.

Is it really free?

Yes, while PRD Studio is in beta. It is rate-limited (20 requests per hour per IP) so everyone gets a turn. No account required.

What do I get in the PRD?

Nine sections: overview and goals, architecture, API, database and ERD, AI prompt design, security, testing, deployment and roadmap, plus an architecture diagram and an ERD.

Can I edit the output?

Absolutely. Treat it as a strong first draft. Copy or download the Markdown and adapt it to your project.

Is the output accurate?

It is AI-generated, so verify anything critical. It is a starting point, not a substitute for your own engineering judgment.

Can I use it in my own app?

Yes. The HTTP API is documented above and returns plain JSON you can call from any client.
